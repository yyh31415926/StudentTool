# 2026-09-25

## 新增「二维码工具」qrcode

- **工具 id**：`qrcode`，名称「二维码工具」，分类 `dev`，order 8。
- **功能**：内容转二维码（文字/URL/中文/Emoji，尺寸/前景色/背景色/纠错等级 L/M/Q/H/模块样式 方形·圆点·圆角，实时预览 + 复制图片/下载 PNG/SVG/清空，静区保留，对比度不足提示）；二维码转内容（上传/拖拽/粘贴 PNG·JPG·WebP，≤5MB，本地识别，多码识别第一个，复制结果，识别后释放 Object URL）。第一版不做摄像头扫描。
- **依赖**：`qrcode`（编码，取位矩阵）+ `@types/qrcode`；`jsqr`（解码，仅解码时动态 `import()` 懒加载）。
- **架构决策**：未新增第 6 个模板（AGENT_RULES §4.5 🔴 模板 ≤5）。改用 §4.3/§8.2 预留的 **`customUI` 机制**：
  - `src/types/tools.ts`：`template` 改为可选、新增 `customUI?: string`（向后兼容）。
  - 新增 `src/components/tools/custom/registry.tsx` + `custom/qrcode/`（QRCodeTool / EncodePanel / DecodePanel / StyleControls / DownloadActions）。
  - 工具页 `src/app/tools/[toolId]/page.tsx`：customUI 优先于 template 解析。
- **新增文件**：`src/lib/tools/qrcode.ts`（纯函数核心）、`src/lib/tools/definitions/qrcode.ts`、`src/components/tools/custom/*`、`tests/tools/qrcode.test.ts`。
- **修改文件**：`src/types/tools.ts`、`src/lib/tools/definitions/index.ts`、`src/app/tools/[toolId]/page.tsx`、`tests/tools/categories-data.test.ts`（dev 快照 6→7）。
- **验证**：测试 222/222 通过（含 qrcode 35 组：边界 + 中文/Emoji 编码→解码往返）；`tsc --noEmit` 通过；`eslint` 0 错误；生产构建 16 个静态页（含 /tools/qrcode）通过；运行时冒烟：首页/分类/dev 分类页/工具页/sitemap 均含 qrcode。
