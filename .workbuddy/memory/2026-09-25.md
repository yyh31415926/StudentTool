- **工具 id**：`qrcode`，名称「二维码工具」，分类 `dev`，order 8。
- **功能**：内容转二维码（文字/URL/中文/Emoji，尺寸/前景色/背景色/纠错等级 L/M/Q/H/模块样式 方形·圆点·圆角，实时预览 + 复制图片/下载 PNG/SVG/清空，静区保留，对比度不足提示）；二维码转内容（上传/拖拽/粘贴 PNG·JPG·WebP，≤5MB，本地识别，多码识别第一个，复制结果，识别后释放 Object URL）。第一版不做摄像头扫描。

  - 工具页 `src/app/tools/[toolId]/page.tsx`：customUI 优先于 template 解析。
- **新增文件**：`src/lib/tools/qrcode.ts`（纯函数核心）、`src/lib/tools/definitions/qrcode.ts`、`src/components/tools/custom/*`、`tests/tools/qrcode.test.ts`。
- **修改文件**：`src/types/tools.ts`、`src/lib/tools/definitions/index.ts`、`src/app/tools/[toolId]/page.tsx`、`tests/tools/categories-data.test.ts`（dev 快照 6→7）。

## 修复「复制二维码图片」非安全上下文兜底

- 问题：HTTP 局域网（`http://YYH:3000` / `http://局域网IP:3000`）下浏览器因非安全上下文拒绝图片剪贴板。
- 修复（`src/components/tools/custom/qrcode/QRCodeDownloadActions.tsx`）：
  - 新增 `supportsImageClipboard()`，复制前四重检测：`window.isSecureContext`、`navigator.clipboard`、`navigator.clipboard.write`、`ClipboardItem`（= window.ClipboardItem）。
  - 支持时：SVG→PNG Blob→`ClipboardItem` 写入 `image/png`，成功提示「二维码图片已复制到剪贴板」。
  - 不支持或被拒时：自动 `fallbackDownloadPng()` 下载 PNG 兜底，提示「当前浏览器或 HTTP 局域网环境不支持直接复制图片，已自动下载 PNG 文件。」（不再只报「操作失败」）。
  - 复制按钮在无内容时仍禁用，有内容时始终可用（不因不支持而禁用）。
  - 不改变「下载 PNG」「下载 SVG」行为。
- 验证：tsc 通过、eslint 0 错误、测试 222/222 通过（组件无单测）。
- 遗留观察：全站 `text-error` 语义色在 globals.css 的 token 中未定义（既有工具同样在用，属历史遗留，未在本次处理）。

## 新增「图片文字识别」image-ocr

- **工具 id**：`image-ocr`，名称「图片文字识别」，分类 `text`，order 9，`customUI: "image-ocr"`。
- **功能**：选择 / 拖拽 / 粘贴图片（PNG·JPG/JPEG·WebP，单张 ≤10MB，最长边 >8192px 报错，识别前缩到长边 ≤2500px）→ 选择语言（简体中文 chi_sim / 英文 eng / 中英混合 chi_sim+eng，默认中英混合）→ 本地 OCR → 复制结果。图片只在浏览器本地处理，不上传。
- **依赖**：`tesseract.js@7.0.0`（仅识别时动态 `import()` 懒加载；模型权重默认从 CDN 加载，属已知限制，正式上线前可改自托管）。
- **架构决策**：沿用 qrcode 的 `customUI` 机制（模板 ≤5 红线不变），未新增模板；纯函数核心 `src/lib/tools/image-ocr.ts`（图片类型/大小/尺寸校验、语言归一化、缩放计算、`run` 入口），真正的 OCR 异步逻辑在 `custom/image-ocr/ImageOcrTool.tsx`。
- **新增文件**：`src/lib/tools/image-ocr.ts`、`src/lib/tools/definitions/image-ocr.ts`、`src/components/tools/custom/image-ocr/ImageOcrTool.tsx`、`tests/tools/image-ocr.test.ts`（27 组）。
- **修改文件**：`src/lib/tools/definitions/index.ts`、`src/components/tools/custom/registry.tsx`、`tests/tools/categories-data.test.ts`（text 快照 1→2）。
- **验证**：测试 249/249 通过；`tsc --noEmit` 通过；`eslint` 0 错误；生产构建 17/17 静态页（含 /tools/image-ocr，此前 16 页）通过。
- **未验证**：真实 OCR 识别准确率（需浏览器真机实测，测试环境无）；tesseract.js CDN 在中国大陆的可达性；真机移动端布局与软键盘遮挡；带 EXIF 旋转的 JPG 识别。
- **备注**：本工具属「文件上传类（图片处理）」工具，落在 v0.2 §6.2 / AGENT_RULES §2.2、§9.2 的 v1 禁止范围内；按用户明确指令（本地 OCR、不上传、不接 API、不接摄像头）视为对上述红线的明确豁免执行。
